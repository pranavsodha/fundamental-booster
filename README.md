🚀 Fundamental Booster – Interactive Personal Data Collector

📌 About the Project

Fundamental Booster is a beginner-friendly Python project that collects basic personal information from the user through the terminal.

The program asks the user for their:

- Name
- Age
- Height
- Favorite number

After collecting the information, it displays the entered data along with the data type and memory address of each variable.

This project was created to practice the fundamental concepts of Python programming.

---

🎯 Features

- 🧑 Collects user's name
- 🎂 Collects user's age
- 📏 Collects user's height
- 🔢 Collects user's favorite number
- 🔍 Displays the data type of each value
- 🧠 Displays the memory address using "id()"
- 📅 Calculates an approximate birth year
- 💬 Provides an interactive terminal-based experience
